# Event Floorplan AI（MVP）

施設の図面（PDF・画像・写真）から、イベントの運営図面を作るツール。
**AIは図面を読み、方針を考える。座標・寸法・検証・描画はプログラムが正確に行う。**

```
図面を読み込む → 会場をデータ化（AI読み取り＋人が確認） → 条件を入れる
→ 配置案を3つ生成 → ブラウザで編集 → PowerPoint / PDF / SVG / PNG に出力
```

## 動かす

```bash
npm install
npm run dev        # 開発サーバー
npm test           # エンジン・取り込み・出力のテスト（11件）
npm run smoke      # 会場タイプ別に配置→検証→SVG/PPTX書き出し（out/ に出力）
npm run build      # dist/ に静的ビルド（Vercel などにそのまま置ける）
```

## できること

| 設計メモの項目 | この版 |
| --- | --- |
| PDF・画像・写真の読み込み | PDF（ページ選択・文字抽出）、画像、写真の台形補正（4点指定）、90°回転 |
| 図面の構造化 | 輪郭・柱・出入口・固定設備を mm 単位の JSON に。AI読み取り → 直角補正・壁スナップ → 人が頂点を修正 |
| 縮尺 | 図面の寸法記載（AIが読めた場合）、2点の実寸指定、横幅指定 |
| AI配置案 | 5種類のイベント × 3方針。AIは方針（`LayoutSpec`）だけを返し、幾何エンジンが配置 |
| 検証 | 重なり、会場外、柱・固定設備との干渉、出入口前、通路幅、収容、到達可能性、最遠席→出口の歩行距離 |
| 編集 | ドラッグ・リサイズ・回転・複製・Undo/Redo・レイヤー・グリッド吸着・動線の折れ点編集・言葉での編集 |
| 出力 | PPTX（壁・席・ブース・矢印・文字をネイティブ図形で）、PDF、SVG、PNG、プロジェクトJSON |
| 出力スタイル | 企画書用 / 運営スタッフ用（寸法・全動線・設備リスト）/ プレゼン用（ゾーニング）/ 図面のみ |

## 構成

```
src/
  core/      データモデルと幾何（UIに依存しない。Nodeでもそのまま動く）
    types.ts      Project / Venue / Obj / Plan / LayoutSpec（内部座標はすべて mm）
    planner.ts    配置エンジン：LayoutSpec → 正確な配置
    validate.ts   幾何チェック
    route.ts      動線の自動ルーティング（什器を避け、通路の中央を通す）
    analysis.ts   AIの読み取り結果 → 会場データ
    ops.ts        編集操作（UIとAIチャット編集の共通の入口）
    glyphs.ts     種別ごとの描き方 → 描画プリミティブ
    prims.ts      プリミティブを Canvas / SVG に描く
  render/    シート構成（scene → sheet）と PPTX / SVG / PNG / PDF
  ai/        AI連携（読み取り・方針立案・言葉での編集）
  io/        ファイル読み込み・台形補正・保存
  ui/        React + Konva の編集画面
```

キャンバス・SVG・PPTX は**同じプリミティブ列**から描くので、画面と出力がずれません。

## AIの差し替え

AIを呼ぶのは `src/ai/claude.ts` だけです。この版は Claude のアーティファクト内で動かす前提で、
閲覧者自身の Claude を使います（APIキー不要）。Vercel などに単体で置く場合、AI以外の機能
（手動での会場作成・ルールによる配置・編集・出力）はそのまま動きます。
別のAPI（設計メモで想定していたモデルなど）に替えるときは、次の3関数を同じ入出力で実装し直せば済みます。

- `analyzeFloorplan(source)` → `AnalysisRaw`（0–1000 正規化座標）
- `proposeSpecs(project)` → `LayoutSpec` の配列
- `chatEdit(project, plan, command)` → 操作のリスト

## まだやっていないこと

- **PDFのベクター情報からの壁抽出**・OpenCV による線検出（今は AI の視覚読み取り＋人の修正）
- 図面記号の専用検出モデル（YOLO / セグメンテーション）
- サーバー保存・共同編集（今はブラウザ内の自動保存と JSON ファイル）
- DXF 出力、3D 化
- 実図面での精度検証セット（壁・柱・出入口・寸法を要素別に測る）

避難・防災・収容人数の判定は幾何計算による**確認の補助**です。法令・施設規定・消防協議で確定してください。
